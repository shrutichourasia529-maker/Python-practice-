# Number Guessing Game 🎯

This is my first Python mini project.

## About the Game
- Computer randomly selects a number between 1 and 10
- User gets 5 chances to guess the correct number
- Remaining attempts are shown after each wrong guess
- Game ends when the number is guessed or attempts are over

## Concepts Used
- Python random module
- while loop
- if-else conditions
- user input

## How to Run
Run the file using Python:
python number_guessing_game.py

## Learning Purpose
This project helped me practice basic Python concepts and logic building.
